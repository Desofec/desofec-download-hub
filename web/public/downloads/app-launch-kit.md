# First App Launch Kit

By Desofec AI Studio. Take a small app idea to a published first version.

## 1. Define a tiny scope
- Problem: "[WHO] struggles to [TASK]."
- One core feature. Everything else goes on a "later" list.
- Pick a deadline of one to two weeks.

## 2. Plan the screens
- Sketch 2 to 4 screens on paper.
- Write what the user taps and what happens next.

## 3. Build
1. Set up your project in VS Code, or Replit if you prefer the browser.
2. Track your work with Git and store it on GitHub.
3. Build the core feature first, then add simple styling.
4. Commit after each small step.

Tip: describe one small task at a time to an AI coding assistant such as GitHub Copilot or OpenAI Codex, read the result, and run it before moving on.

## 4. Test
- Try empty, very long and unexpected input.
- Ask a friend to use it without instructions and watch quietly.

## 5. Publish
- Deploy to a free host such as Vercel and share the link.
- Write down three improvements for the next version.

## Using AI well
- "Explain this error and suggest a fix: [ERROR]"
- "Review my code for bugs and unclear names: [CODE]"
- Never paste passwords or secret keys into an AI tool, and always test generated code.
