# Design Starter Kit

By Desofec AI Studio. A simple routine for turning an idea into a clear design.

## 1. Start with the purpose
- Who is this for? What should they be able to do?
- Write it in one sentence and keep it visible.

## 2. Core principles
- **Hierarchy**: the most important thing should be the most noticeable.
- **Contrast**: make text easy to read against its background.
- **Spacing**: give elements room; group related things together.
- **Consistency**: reuse the same fonts, colors and button styles.

## 3. Prototype routine
1. Collect 3 examples you like and note why.
2. Sketch two versions on paper.
3. Build the better one in Figma, Canva or Framer.
4. For physical ideas, model a simple version in Autodesk Fusion (formerly Fusion 360).

## 4. Feedback checklist
- Can someone tell what it is in five seconds?
- Is the main action obvious?
- Is the text readable on a phone?
- What did they find confusing?

## AI helpers

- Treat AI suggestions as starting points and use your own judgment.
