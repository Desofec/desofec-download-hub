# Website Starter Bundle

By Desofec AI Studio. Plan, build and publish a small online project.

## Step 1: Define the project (15 min)
- Purpose: what should a visitor do or learn?
- Audience: who is it for?
- Pages: Home, About, one content page, Contact.

## Step 2: Tools
- **Design**: Figma for a quick layout sketch.
- **Code**: VS Code with an HTML/CSS/JS project.
- **Version control**: GitHub to store your code.
- **Hosting**: GitHub Pages for free static hosting.

## Step 3: Minimal project structure
    my-site/
      index.html
      about.html
      style.css
      script.js

## Step 4: Page checklist
- A clear headline and one primary button.
- A descriptive `<title>` and meta description on every page.
- Images with alt text.
- Readable on mobile; test by narrowing your browser window.

## Step 5: Publish on GitHub Pages
1. Create a repository and push your files.
2. Open Settings -> Pages.
3. Choose the branch to deploy and save.
4. Visit the URL shown after a minute or two.

## Launch checklist
- All links work.
- No placeholder text remains.
- Contact method is tested.
- Share it with one person and ask what was confusing.
