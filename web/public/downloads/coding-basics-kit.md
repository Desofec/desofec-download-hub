# Coding Basics Kit

By Desofec AI Studio. Learn by building small things.

## Core concepts
- **Variables**: named boxes that hold values.
- **Conditions**: `if` this, do that.
- **Loops**: repeat steps over a list.
- **Functions**: reusable named blocks of logic.
- **Data structures**: lists/arrays and objects/dictionaries.

## Four-week plan (30-45 min a day)
- **Week 1**: variables, types, printing output.
- **Week 2**: conditions and loops.
- **Week 3**: functions and lists.
- **Week 4**: build one mini project and share it.

## Practice tasks
1. Print a greeting using a name stored in a variable.
2. Write a function that returns the larger of two numbers.
3. Loop over a list of numbers and sum them.
4. Count how many words are in a sentence.
5. Make a simple FizzBuzz for numbers 1-30.

## Mini-project ideas
- Tip calculator.
- To-do list in the browser.
- Quiz game with a score.
- Unit converter.

## Set up in 20 minutes
1. Install VS Code and Python.
2. Create a folder `practice` and a file `hello.py` with `print("Hello")`.
3. Run it from the VS Code terminal with `python hello.py`.
4. Save your work with Git: `git init`, `git add .`, `git commit -m "First commit"`.

## Using AI to learn
Ask for explanations, not just answers: "Explain this line by line and give me a similar exercise." Always type and run the code yourself.

## When you're stuck
1. Read the error message from the bottom up.
2. Print values to see what is happening.
3. Shrink the problem until it works, then grow it back.

## Good prompts for coding assistants
Tools like GitHub Copilot and OpenAI Codex can help you learn faster:
- "Explain this function line by line like I'm a beginner."
- "Give me three similar exercises, without solutions."
- "Where could this code fail? Show me a test input."
Try to solve first, then compare with the assistant's answer. Never paste secrets or keys.
