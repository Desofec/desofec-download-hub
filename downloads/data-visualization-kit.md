# Data Visualization Starter Kit

By Desofec AI Studio. Ask a clear question, make an honest chart, and explain what the data can and cannot tell you.

## A simple workflow
1. Write one question the chart should answer.
2. Check what each row means, and label columns and units.
3. Choose a chart for the question: line for time, bars for groups, scatter for relationships, histogram for spread, heat map for location.
4. Label axes, units, sample size and uncertainty.
5. Check the chart against the source data and write one limitation.

## Colab prompt
“I have a CSV with columns [names]. Each row represents [observation]. My question is [question]. Recommend a chart and explain why it fits. Then write a short Python script to make it, label units, and save it as a PNG. Do not remove or alter data.”

## Chart review checklist
- Does the chart answer the question?
- Are labels, units and sample size clear?
- Is the scale honest and readable?
- Are missing values or outliers explained, not hidden?
- Does the caption separate observation from interpretation?

Use anonymised or practice data with online tools. A chart shows evidence; it does not prove causation by itself.
