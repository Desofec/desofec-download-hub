# AI Website Builder Kit

By Desofec AI Studio. Plan a small website, let AI draft it, then review and publish it yourself.

## 1. Website brief (fill this in first)
- **Who is it for?** (one type of visitor)
- **What is the one action they should take?** (contact you, read a post, buy, sign up)
- **Pages or sections:** (for a first site: Home, About, Contact on a single page)
- **Tone:** (friendly, professional, playful)
- **What I already have:** (text, logo, photos I own)

## 2. Draft prompt
“Create a single-page website as one index.html file with embedded CSS. Audience: [who]. Goal: [one action]. Sections: [list]. Tone: [tone]. Use semantic HTML, a readable font size, good colour contrast and a layout that works on phones. Use placeholder text in [square brackets] that I can replace. Do not add tracking scripts or external libraries.”

## 3. Review prompt
“Review this page for: mobile layout, heading order, link text that makes sense out of context, image descriptions, colour contrast and anything that sounds like a claim I cannot prove. List problems first, then suggest fixes. Do not rewrite everything.”

## 4. Before you publish
- Replace every [placeholder] and read the page out loud once.
- Check every link, email address and phone number.
- Only use images, logos and text you have the right to use.
- Do not publish personal data that is not meant to be public.
- Keep your own copy of the files.

## 5. Publish for free (one common route)
1. Put the files in a GitHub repository.
2. Import the repository into a free hosting service such as Vercel.
3. Open the live address on your phone and ask a friend to test it.

Plans and menu names change, so follow each service's current instructions.
