# AI Coding Prompt Pack

By Desofec AI Studio. Use coding assistants like GitHub Copilot and OpenAI Codex to learn, not to skip learning.

## Golden rules
- Ask for one small task at a time.
- Read the code before you run it.
- Test everything. AI can be confidently wrong.
- Never paste passwords, API keys or private data.

## Prompt template
"I am a beginner using [LANGUAGE]. I want to [GOAL]. Input: [INPUT]. Expected output: [OUTPUT]. Explain your solution step by step."

## Learning prompts
- "Explain this code line by line: [CODE]"
- "Give me 3 practice exercises on [TOPIC], without solutions."
- "What is the difference between [A] and [B]? Show a tiny example."

## Building prompts
- "Suggest a folder structure for a small [APP TYPE] app."
- "Write the function [NAME] that [DOES X]. Keep it simple and add comments."
- "Turn this feature into a list of small steps I can build one by one."

## Debugging prompts
- "Explain this error and the most likely cause: [ERROR]"
- "Here is my code and the wrong output. Help me find the bug without rewriting everything: [CODE]"
- "What edge cases should I test for this function?"

## Review prompts
- "Review this code for bugs, unclear names and missing checks: [CODE]"
- "How can I make this function shorter and easier to read?"

## Weekly habit
1. Solve a task on your own first.
2. Ask the assistant for a different approach.
3. Compare, then write down what you learned.
